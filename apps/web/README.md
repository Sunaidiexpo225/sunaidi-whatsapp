# @sunaidi/web

Next.js (App Router) web app, deployed to Vercel. Owns the UI:

- Shared team inbox with realtime updates (Supabase Realtime), 24h-window indicator
  and template fallback, internal notes, canned replies.
- Event switcher: one login across all events, each with its own inbox and reports.
- Contacts, tags and segments; template editor; campaign builder and reports; dashboard.
- Bilingual Arabic (RTL) and English via `next-intl`.
- Auth via Supabase Auth.

Scaffolded in a follow-up PR.
